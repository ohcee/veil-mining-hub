Building from Source

        

          
If you want to build XMRig-Veil on Ubuntu:

          
sudo apt install git build-essential cmake libuv1-dev libssl-dev libhwloc-dev
git clone https://github.com/us77ipis/xmrig-veil.git
mkdir xmrig-veil/build && cd xmrig-veil/build
cmake ..
make -j$(nproc)

          
For Solo Mining without a pool, you must run a local Veil node and the Veil Stratum Proxy.
