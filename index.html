Unified Build Guide for XMRig-Veil & Stratum Proxy

📦 XMRig-Veil Source 🛰️ Veil Stratum Proxy ⛏️ WildRig (Legacy ProgPoW)

Apple Silicon & Intel Build

Requires Homebrew

1. Install dependencies:

brew install cmake libuv openssl hwloc

2. Compile XMRig-Veil:

git clone https://github.com/ohcee/xmrig-veil.git
mkdir xmrig-veil/build && cd xmrig-veil/build
cmake .. -DOPENSSL_ROOT_DIR=$(brew --prefix openssl)
make -j$(sysctl -n hw.logicalcpu)

MSYS2 Build (Recommended)

1. Install MSYS2 and extract Prebuilt Deps to C:\xmrig-deps.

2. Open **MSYS2 UCRT64** and run:

pacman -S mingw-w64-ucrt-x86_64-gcc git make
git clone https://github.com/ohcee/xmrig-veil.git
mkdir xmrig-veil/build && cd xmrig-veil/build
cmake .. -G "Unix Makefiles" -DXMRIG_DEPS=c:/xmrig-deps/gcc/x64
make -j$(nproc)

Ubuntu / Debian / Linux Build

Install dependencies and build from source:

sudo apt install git build-essential cmake libuv1-dev libssl-dev libhwloc-dev
git clone https://github.com/ohcee/xmrig-veil.git
mkdir xmrig-veil/build && cd xmrig-veil/build
cmake ..
make -j$(nproc)

Veil Stratum Proxy (Solo Mining)

Run this to connect your built XMRig to a local Veil node:

git clone https://github.com/ohcee/veil-node-stratum-proxy.git
cd veil-node-stratum-proxy
# Build/Run proxy (ensure Python 3 is installed)
python3 veilproxy.py -p 5555 -n http://user:pass@127.0.0.1:8332
